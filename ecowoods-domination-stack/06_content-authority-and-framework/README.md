# Content authority

The citable object is the Well-Installed Framework v1.0 (six pillars, 27 criteria, published 2026-08-19), not a blog post that repeats it.

After a crawl, `reports/framework_criteria.json` holds the questions extracted from `/api/knowledge` when that payload includes them. If the extractor finds a different count than 27, believe the extractor and fix the public copy.

Do not paste the technical papers into other domains to manufacture citations. One accurate outbound citation of `/framework` from a site Ecowoods does not own is the move.
