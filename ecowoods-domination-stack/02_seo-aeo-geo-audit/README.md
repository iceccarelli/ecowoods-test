# SEO, AEO, GEO

SEO score uses indexability (sitemap 200-rate, titles, H1s, schema types present, TTFB) and penalises HTML weight and missing Markdown twins.

AEO/GEO score uses the machine surfaces that already exist: `/llms.txt`, `/llms-full.txt`, `/ai.txt`, `/api/knowledge`, the framework, dated review lines, and price bands. Stale `Facts current as of` dates cost points after 21 days.

This is not a replacement for the repo's own `scripts/verify-*.mjs` suite. Those scripts grade the source. This folder grades the deployed response.
